## 📌 Projetos em destaque



### ⚙️ Projeto Jenkins — Spring Boot + CI/CD

Projeto desenvolvido durante minha formação com o objetivo de aplicar conceitos de desenvolvimento backend com Java e Spring Boot, integração com banco de dados e automação de processos utilizando Jenkins.

A aplicação consiste em uma API REST para gerenciamento de tarefas, permitindo cadastrar, consultar, filtrar e atualizar atividades armazenadas em um banco de dados MySQL.

O projeto também utiliza Docker para containerização da aplicação e Jenkins para automatização do processo de integração e entrega do projeto.

- ⚙️ Funcionalidades
- 📝 Cadastro de tarefas
- 📋 Listagem de todas as tarefas
- 🔎 Busca de tarefas por título
- 🟢 Listagem de tarefas abertas
- ✅ Listagem de tarefas finalizadas
- 🔄 Atualização de tarefas
- 🗄️ Persistência dos dados em MySQL
- 🐳 Containerização da aplicação com Docker
- 🔄 Automação do projeto utilizando Jenkins


***Tecnologias***: Java, Springboot, Linux, Docker, Jenkins e MySQL.

🔗 [Ver projeto](https://github.com/Isack2022/Projeto-Jenkins)

### 👥 Seensus Group

Projeto acadêmico desenvolvido em equipe com o objetivo de dar maior visibilidade a pequenos estabelecimentos, permitindo que usuários encontrem lojas, consultem informações sobre os estabelecimentos e utilizem recursos de busca e filtros.

A aplicação foi desenvolvida como uma plataforma web inspirada na ideia de concentrar diferentes pequenos negócios em um único ambiente digital, facilitando sua divulgação e descoberta pelos usuários.

Durante o desenvolvimento, participei da construção da aplicação utilizando Node.js e Express no backend, MySQL para gerenciamento do banco de dados, além de HTML, CSS, Bootstrap e JavaScript no desenvolvimento da interface.

O projeto também utilizou Docker para configuração do ambiente e Fedora Linux durante o desenvolvimento e execução da aplicação.

#### Principais funcionalidades:

- 🏪 Listagem de estabelecimentos
- 🔎 Busca e filtros
- 📍 Informações e localização das lojas
- ⭐ Avaliações
- 📄 Página com detalhes de cada estabelecimento

**Tecnologias**: Node.js, Express, MySQL, HTML5, CSS, Bootstrap, JavaScript, Docker e Fedora Linux.

> ℹ️ Status: projeto acadêmico concluído. A aplicação utilizava um banco de dados MySQL em ambiente local e, atualmente, a demonstração online não está disponível.
